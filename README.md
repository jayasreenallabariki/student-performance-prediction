# Student Performance Prediction

A Python-based supervised machine learning project that predicts a student's percentage score based on the number of study hours.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Project Overview
This project explores the relationship between the number of hours a student studies and the percentage score achieved.

The dataset is analyzed and visualized before training a Linear Regression model to predict student scores based on study hours.

## Implementation
- Loaded and explored student performance data using Pandas.
- Checked the dataset for missing values.
- Visualized the relationship between study hours and student scores.
- Split the dataset into training and testing sets.
- Trained a Linear Regression model using Scikit-learn.
- Generated predictions using the trained model.
- Evaluated the model by comparing actual and predicted results.

## How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Open `student_performance_prediction.ipynb` in Jupyter Notebook.
4. Run the notebook cells sequentially.

## Project Purpose

This project demonstrates foundational Python programming, data processing, visualization, supervised machine learning, model training, and evaluation.
